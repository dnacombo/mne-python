Add :func:`mne.stats.cluster_level.cluster_test`, a Wilkinson-formula-based interface to cluster-based permutation testing (supporting between-group, paired, and repeated-measures ANOVA designs) that returns a :class:`~mne.stats.cluster_level.ClusterResult` with :meth:`~mne.stats.cluster_level.ClusterResult.plot_cluster_time_sensor` and :meth:`~mne.stats.cluster_level.ClusterResult.plot_cluster_time_frequency` plotting helpers, the latter selectable by cluster mass via its ``cluster_idx`` parameter, by `Carina Forster`_.
